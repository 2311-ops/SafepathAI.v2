# Quick Task 260814-j70: Apply Home Map screen redesign (status pill + draggable sheet + pin rings) Summary

Restructured `LiveMapScreen`'s top overlay into a slim identity/status pill bar plus a
draggable bottom action sheet, and gave every map pin a presence-colored ring with an
animated pulse ring on the self ("You") pin — a presentation-layer-only pass over the
existing Home Map, per the user's redesign spec.

## What Changed

**`mobile/lib/features/home/presentation/main_shell.dart`** — Added a public top-level
constant `kShellBottomBarHeight = 124` (nav bar + raised SOS disc overhang, doc-commented),
and replaced the previously hard-coded `124` in the bottom-nav `SizedBox` with it. This is
the only edit to this file; `SosArmButton`, `_onArmComplete`, `sosControllerProvider`,
`pushNamed('sos-session')`, `_tabs`, `_NavItem`, and the `IndexedStack` children are
byte-identical to before.

**`mobile/lib/features/location/presentation/live_map_screen.dart`**:

- `_LiveMapScreenState.build`'s `Stack` grew a third layer. Layer 1 (`VectorMap`) is
  unchanged. Layer 2 is now `SafeArea(bottom: false, ...)` wrapping the top cluster
  (`_MapTopBar`, the existing `_MemberStatusRail`, and the existing conditional
  `LowBatteryBanner`). Layer 3 is a new `Positioned.fill(bottom: kShellBottomBarHeight,
  child: DraggableScrollableSheet(...))` resting at `initialChildSize: 0.2` /
  `minChildSize: 0.2`, opening to `maxChildSize: 0.5`, with `snap: true` and
  `snapSizes: [0.2, 0.5]`.
- Replaced `_LiveMapOverlay` (a tall panel with a `'Your family, live'` title, two
  `_StatusCountChip`s in a `Wrap`, and both action buttons) with `_MapTopBar` — a slim
  pill-shaped row: `MemberMapPin` identity pin (`size: 36`, still live-reading
  `state?.selfPosition`), a new `_FamilyStatusPill` ("N online · N offline", lowercase so
  it can never collide with the marker `ONLINE`/`OFFLINE` labels), the profile
  `IconButton.filledTonal`, and `LogoutAction`. Kept the original 260ms
  fade-and-rise `TweenAnimationBuilder` entrance.
- `ManageSafeZonesButton` and `ViewNotificationsButton` moved into the new bottom sheet's
  `ListView` (grab handle, then the Guardian-gated Manage-safe-zones button, then
  Notifications), both full-width, both keeping their existing `context.push` targets and
  `minimumSize: Size(48, 48)`.
- Deleted `_LiveMapOverlay` and `_StatusCountChip` (both now unreferenced) and the
  `'Your family, live'` string.
- `LiveMemberMarker` converted from `StatelessWidget` to `StatefulWidget`
  (`SingleTickerProviderStateMixin`) with a byte-identical public constructor. The 36x36
  avatar's border now colors `AppColors.safe` (online) or `AppColors.bodySecondary`
  (offline) instead of a fixed white ring, with a new zero-blur `spreadRadius: 1.5` white
  halo shadow preserving separation from the basemap. The avatar now sits inside a fixed
  56x56 slot (same for every marker, self or not, so pin anchor points stay aligned); the
  self pin additionally draws an `_SelfPulseRingPainter`-driven expanding ring (radius
  20->28px, teal stroke fading 0.5->0 opacity, 1800ms loop) behind the avatar, gated on
  `isSelf && !MediaQuery.of(context).disableAnimations` and started/stopped in
  `didChangeDependencies`/`didUpdateWidget`, matching `sos_arm_button.dart`'s reduce-motion
  convention. `OverlayMarker.height` raised `108` -> `128` to fit the larger avatar slot.

**Tests** — `location_permission_gate_test.dart`'s three now-dead `'Your family, live'`
sentinels were replaced with `find.byType(LiveMapScreen), findsNothing`. Added three tests
to `live_map_screen_test.dart` (status pill copy, sheet size/contents, Guardian gate inside
the sheet) and three to `live_member_marker_test.dart` (online ring color, offline ring
color, self-only pulse-ring key), all following each file's existing fixed-duration-pump /
`tester.pump()`-only convention (never `pumpAndSettle`, since the self pin now animates
forever).

## Already Spec-Compliant — Not Touched

Per the plan's investigation findings, two parts of the redesign spec were already met by
the existing implementation and were explicitly left alone by this task:

- **SOS button**: 72px, deep red (`AppColors.sosRed`), center-bottom, hold-to-activate with
  a 3-second press ring (`sos_arm_button.dart`, `SosArmRingPainter`). Nothing in
  `sos_controller.dart`, `sos_session_state.dart`, `sos_arm_button.dart`,
  `sos_arm_ring_painter.dart`, or `sos_countdown.dart` was edited.
- **Four-tab bottom nav** (Map, Activity, Insights, Privacy) — unchanged except the single
  `kShellBottomBarHeight` constant extraction described above.
- **OpenFreeMap Liberty basemap** — accepted as already muted/flat; `maplibre_gl` exposes
  only a whole-style URL (`styleString`), so there is no per-property "muted" knob and no
  style change was made.
