# Quick Task 260811-65q: Redesign Manage Permissions Screen Summary

**Replaced ManagePermissionsScreen's truncating SegmentedButton with a vertical full-width permission-row selector, added ProfileAvatar + capitalized-name + permission-badge member cards, and moved "Remove from circle" behind a PopupMenuButton overflow menu.**

## Performance

- **Duration:** ~20 min
- **Completed:** 2026-08-11T01:38:35Z

- **Files modified:** 1

## Accomplishments
- Added `_PermissionLevelRow` (private `StatelessWidget`) and `_iconForPermissionLevel` helper, replacing the `SingleChildScrollView`/`SegmentedButton<PermissionLevel>` block with a `Column` of three always-full-width, real-Material-icon rows (`Icons.visibility_outlined` / `Icons.location_on_outlined` / `Icons.notifications_outlined`) that can never truncate regardless of device width — selected row filled `AppColors.primaryTeal` + trailing check icon, unselected rows outlined in `AppColors.hairline`.
- Added a "Permissions" `AppTypography.heading` + `AppTypography.bodySecondary` subtitle inside the `ListView`, matching `privacy_center_screen.dart`'s established heading pattern, additive to the unchanged `AppBar`.
- Each member card now shows a reused `ProfileAvatar` (44px, identity color alternating `AppColors.memberViolet`/`AppColors.memberPink` by list index via `otherMembers.indexed`), a defensively capitalized display name (`_capitalized()`, display-only — never mutates `member.displayName`), and `member.permission.label` as a secondary at-a-glance badge beneath the name.
- "Remove from circle" moved from an always-visible inline red `InkWell` row into a `PopupMenuButton` (`Icons.more_vert`) overflow menu in the card's top-right; selecting it still calls the exact same, unmodified `_confirmRemove(context, ref, familyId, member, circleName)` — same `AlertDialog` copy, same `AppColors.sosRedDeep` confirm styling, same `removeMember` call.
