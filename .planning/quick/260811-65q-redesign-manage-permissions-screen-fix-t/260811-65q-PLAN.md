Read the live file first — line numbers may have shifted since planning.

**1a — New private row widget.** At the bottom of the file, after the `ManagePermissionsScreen`
class closes, add a private `StatelessWidget` named `_PermissionLevelRow` with a `const`
constructor taking three required fields: `level` (`PermissionLevel`), `selected` (`bool`), and
`onTap` (`VoidCallback`). Its `build()` returns an `InkWell(onTap: onTap, borderRadius:
BorderRadius.circular(12), child: Container(...))`. The `Container` must set `width:
double.infinity` (so the row always fills the card's content width — this is what guarantees
"full-width, never truncated," independent of device width or label length) and `padding:
const EdgeInsets.symmetric(horizontal: AppSpacing.md, vertical: AppSpacing.xsMd)`, with a
`decoration: BoxDecoration(borderRadius: BorderRadius.circular(12), color: selected ?
AppColors.primaryTeal : AppColors.surface, border: selected ? null : Border.all(color:
AppColors.hairline))`. Its child is a `Row` containing, in order: an `Icon` sized 20 using the
icon from a new `_iconForPermissionLevel(level)` helper (see 1b), colored `AppColors.surface`
when `selected` else `AppColors.ink`; `SizedBox(width: AppSpacing.sm)`; an `Expanded(child:
Text(level.label, style: AppTypography.body.copyWith(color: selected ? AppColors.surface :
AppColors.ink)))` (reuse the existing `PermissionLevel.label` getter — do not hardcode label
strings); and, only `if (selected)`, a trailing `Icon(Icons.check, color: AppColors.surface,
size: 20)`.

**1b — Icon mapping helper.** Add a private top-level function `IconData
_iconForPermissionLevel(PermissionLevel level)` (also placed after the class) that switches on
`level` and returns: `Icons.visibility_outlined` for `PermissionLevel.viewOnly`,
`Icons.location_on_outlined` for `PermissionLevel.fullLocation`, and
`Icons.notifications_outlined` for `PermissionLevel.notificationOnly`. Use real Material icon
constants only — never an emoji glyph as an icon substitute, matching this app's existing
Material-icon convention throughout (e.g. `Icons.person_remove`, `Icons.group_off` already in
this same file).

**1c — Replace the selector.** Remove the `SingleChildScrollView`/`SegmentedButton<PermissionLevel>`
block entirely. In its place, insert a `Column` whose children are, `for (final level in
PermissionLevel.values)`, a `Padding(padding: EdgeInsets.only(bottom: level ==
PermissionLevel.values.last ? 0 : AppSpacing.sm), child: _PermissionLevelRow(level: level,
selected: level == member.permission, onTap: () =>
ref.read(familyControllerProvider.notifier).updatePermission(familyId, member.memberId,
level)))`. This is the same `updatePermission` call already present (only its trigger changes
from segment-selection to row-tap) — do not alter `family_controller.dart` or its signature.

**1d — Screen heading.** Inside the `ListView`'s `children` list (the populated-state branch),
before the `for (final member in otherMembers)` loop, insert: `Text('Permissions', style:
AppTypography.heading)`, `const SizedBox(height: AppSpacing.xs)`, `Text('Control what each
family member can see and do', style: AppTypography.bodySecondary)`, `const SizedBox(height:
AppSpacing.lg)` — matching the exact heading+subtitle composition already established in
`privacy_center_screen.dart`'s `build()`. This is additive to the `AppBar`'s existing back arrow
and 'Permissions' title, not a replacement — do not touch the `AppBar`.

Do not change the two empty-state branches (`familyId == null`, `otherMembers.isEmpty`), the
`ListView`'s outer padding, or the `SafePathCard`/`Padding(bottom: AppSpacing.md)` wrapper around
each member card.
