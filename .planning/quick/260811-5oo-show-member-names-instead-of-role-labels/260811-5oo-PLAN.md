<objective>
Two independent, user-confirmed UI fixes in the Flutter mobile app: (1) Manage Permissions screen shows each member's actual name instead of the literal role word, and (2) Privacy Center collapses its one-card-per-recipient sharing matrix into a single shared control block that applies to every recipient at once.

Purpose: Fix 1 corrects a title bug where every member card renders "Member"/"Guardian" instead of the person's name. Fix 2 removes a UX pattern the user explicitly rejected (per-person cards with duplicated toggles/presets) in favor of one shared control, per direct Q&A this session — both decisions are locked, not open for re-litigation.
Output: `manage_permissions_screen.dart` titles member cards by name (role as fallback only); `privacy_center_screen.dart` renders one shared sharing-controls card wired to the existing per-recipient `toggle`/`startTemporaryShare` API via internal loops, with no backend, controller, model, or theme/token changes.
</objective>
