Read the live file first — line numbers may have shifted since planning.

**Fix 1 — touch target.** On the `InkWell` that wraps the "Remove from circle" `Row`, add
`borderRadius: BorderRadius.circular(8)` as a sibling parameter to `onTap`. Change its `child` from
the current `const Row(...)` to a `Padding` whose `padding` is `const EdgeInsets.symmetric(vertical:
12, horizontal: 8)`, whose `child` is that same `Row` (now non-const, per Fix 2 below). Do not
change the `Icon`'s `size: 18` or the `Row`'s `mainAxisSize: MainAxisSize.min` — only add the
enclosing `Padding` and the `InkWell.borderRadius`.

**Fix 2 — token-derived style.** Replace the "Remove from circle" `Text`'s inline `TextStyle(color:
AppColors.sosRedDeep, fontWeight: FontWeight.w600, fontSize: 13)` with `AppTypography.bodySecondary
.copyWith(color: AppColors.sosRedDeep, fontWeight: FontWeight.w600)`. This makes the label
token-derived (bodySecondary is 14px/500 base, matching every other text style in this file) at the
cost of a ~1px visual size change from the old hardcoded 13px value — acceptable per the task spec,
not a redesign. Because `AppTypography.bodySecondary` is a non-const getter, the enclosing `Row`
(and its `Icon`/`SizedBox` children, which can stay individually `const`) must drop its own top-level
`const` keyword — only the `Text` widget itself becomes non-const.

**Fix 3a — `familyId == null` empty state.** Replace `const Center(child: Text('No circle yet.'))`
with a `Padding(padding: const EdgeInsets.all(AppSpacing.lg), child: Center(child: Column(...)))`
matching `privacy_center_screen.dart`'s `_PrivacyMessage` composition: `mainAxisSize:
MainAxisSize.min`, then in order: `Icon(Icons.group_off, size: 44, color: AppColors.bodySecondary)`,
`SizedBox(height: AppSpacing.md)`, `Text('No circle yet', style: AppTypography.heading, textAlign:
TextAlign.center)` (drop the trailing period so the title matches `_PrivacyMessage`'s exact string
for cross-screen consistency), `SizedBox(height: AppSpacing.xs)`, and a new
`Text('Managing permissions needs an active family circle.', textAlign: TextAlign.center, style:
AppTypography.bodySecondary)`.

**Fix 3b — `otherMembers.isEmpty` empty state.** Keep the existing outer `Padding(padding: const
EdgeInsets.all(AppSpacing.lg), child: Center(child: ...))` structure exactly as-is (do not change
its padding). Change only the `Center`'s `child` from the bare `Text('Just you so far', ...)` to a
`Column` with `mainAxisSize: MainAxisSize.min` containing, in order: `Icon(Icons.diversity_3, size:
48, color: AppColors.bodySecondary)` (matching `invite_member_screen.dart`'s own icon choice and
size for its closely-related "have a circle, need people" state), `SizedBox(height:
AppSpacing.md)`, the existing `Text('Just you so far', style: AppTypography.title, textAlign:
TextAlign.center)` unchanged, `SizedBox(height: AppSpacing.xs)`, and a new `Text('Invite a family
member to manage their permissions here.', textAlign: TextAlign.center, style:
AppTypography.bodySecondary)`.

Do not add a `SafePathCard` wrapper to either empty state — only the icon+title+body `Column`
composition is being adopted from the sibling screens, not their card chrome, since neither existing
branch here is currently card-wrapped. Do not touch the populated `ListView` branch, the
`SegmentedButton`, the confirmation `AlertDialog`, or any import beyond what's already present
(`AppColors`, `AppSpacing`, and `AppTypography` are all already imported).
